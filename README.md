# Art&Co 🎨

## Sobre o projeto

A **Art&Co** é uma loja online desenvolvida como parte de um projeto acadêmico, com o objetivo de criar uma experiência simples e funcional para a compra de materiais artísticos.

O sistema permite a visualização e pesquisa de produtos, organização por categorias, gerenciamento de estoque, carrinho de compras e realização de pedidos.

Além da área destinada aos clientes, o projeto também conta com diferentes níveis de acesso, permitindo que usuários com perfil de **vendedor** e **administrador** tenham acesso a funcionalidades específicas de gerenciamento.

---

## Funcionalidades

Entre as principais funcionalidades disponíveis estão:

- Cadastro e login de usuários;
- Controle de acesso por tipo de usuário;
- Visualização de produtos;
- Pesquisa de produtos;
- Filtro por categorias;
- Carrinho de compras;
- Finalização de compras;
- Histórico de compras;
- Visualização dos detalhes de uma compra;
- Controle de estoque;
- Gerenciamento de produtos;
- Área administrativa;
- Área destinada ao vendedor;
- Dashboard com informações do sistema;
- Interface responsiva utilizando Bootstrap.

---

## Tipos de usuários

O sistema possui três tipos principais de usuários:

### Usuário

Pode navegar pelos produtos, realizar compras e consultar seu histórico de pedidos.

### Vendedor

Possui acesso às funcionalidades destinadas ao gerenciamento de vendas e produtos.

### Administrador

Possui acesso às funcionalidades administrativas do sistema, incluindo o gerenciamento de produtos e outras ferramentas de administração.
