# Art&Co

## Sobre o projeto

A **Art&Co** é uma loja online desenvolvida como projeto acadêmico para a venda de materiais artísticos.

O sistema possui cadastro e login de usuários, controle de acesso, produtos, categorias, estoque, carrinho, compras, histórico de pedidos e áreas específicas para usuários, vendedores e administradores.

## Tecnologias e recursos

* PHP e MariaDB;
* Bootstrap para a interface responsiva;
* API em PHP com retorno em JSON;
* TypeScript para o dashboard;
* CTEs, Views, Stored Procedures, Triggers e função no banco de dados;
* Filtros, rankings e cálculos de dados no dashboard.
